    Not verified by this page. These items never count as passed authentication checks.

    • Ingress isolation: test direct-origin bypass and forged certificate headers. Cloudflare must overwrite the diagnostic headers; only the private tunnel should reach this listener.
    • Session protections: test Secure/HttpOnly cookies, SameSite policy, CSRF, expiry, logout and revocation. This build creates no user sessions.
    • Enrollment and recovery: test single-use expiring invites, username policy, certificate renewal/revocation and rejection of recovery bypasses.
    • Auth0 policy: password AND passkey, token claims, transaction binding and returning-session behavior must be verified together.
    • Other application surfaces: APIs, terminals, logs, previews and sandbox ownership checks are disabled here. Their authorization and WebSocket revocation need testing before re-enabling.
    • Operator security: repository, deployment, provider accounts and secret access require separate controls. This page cannot prove resistance to device or server compromise.
